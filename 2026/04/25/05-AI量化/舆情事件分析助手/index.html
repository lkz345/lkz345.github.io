CASE1 - AI 舆情事件分析助手

项目概述

第一个项目是消息面量化分析系统。在量化投资中，除了基本面和技术面，消息面的重要性不言而喻——市场情绪往往领先于价格变动。

这个项目是基于 nanobot 框架 + Skills 渐进式加载机制搭建的 AI 情报系统。nanobot 是一个轻量级的 Agent 框架，核心特点是 Skills 按需加载：Agent 启动时只加载核心身份定义（AGENTS.md），当识别到用户意图后才动态加载对应的技能指南（SKILL.md），避免 token 浪费。

系统从三个分析维度构建完整的市场情报画像：

维度 关注点 核心脚本
微观（个股） 个股新闻舆情 → 情感评分 → 事件信号 news_fetcher / sentiment_scorer / event_detector
宏观（全球） VIX 恐慌指数 + 原油波动率 + 美债收益率 → 综合恐贪指数 market_fear_index
前瞻性（预测市场） Polymarket 事件概率 + 聪明钱信号 polymarket_monitor

最终输出一份包含量化情绪指数和可操作交易信号的 Markdown 分析报告。

一、微观维度：个股舆情三步分析链路

第一步：多源新闻抓取（news_fetcher.py）

通过 news_fetcher.py 脚本获取个股新闻，采用了多源聚合架构：

  • 东方财富（akshare stock_news_em）：提供行情综述类新闻，覆盖面广
  • DashScope 联网搜索（通义千问 enable_search）：补充实时行业新闻、公告，对小盘股覆盖率更好
  • 央视新闻（可选）：政策面参考

两个数据源的输出统一为 DataFrame 格式，经过关键词过滤、时间范围筛选、标题去重后合并。支持通过 --sources 参数灵活切换数据源组合（em / dashscope / em,dashscope），以及 --stock_name 参数提高搜索精度。

在 Agent 层面，还做了双引擎联网搜索互补：

  • Tavily（内置 web_search）：擅长国际新闻、英文资料
  • DashScope 联网搜索：擅长国内新闻、A股实时信息

个股舆情分析时两个引擎同时调用、合并去重，解决单一搜索引擎对中文小盘股覆盖不足的问题。

第二步：LLM 情感评分 + 交叉验证（sentiment_scorer.py）

这是项目的核心步骤，分两个阶段：

阶段一：逐条分析
将每条新闻通过 LLM（通义千问 qwen3.7-plus）进行结构化情感打分：

  • 情感倾向：正面 / 负面 / 中性
  • 情感强度：1-5 级
  • 关键实体列表
  • 一句话摘要 + 市场影响评估

阶段二：聚合分析 + 交叉验证
逐条分析完后，通过两条独立路线做聚合，映射为恐贪指数（0-100）：

路线 方法 特点
LLM 综合研判 将所有逐条结果汇总后交给 LLM 做整体评估 能识别主题、风险点、交易机会
强度加权统计 纯算法：index = 50 + (正面加权占比 - 负面加权占比) × 50 独立于 LLM，结果稳定可复现

两条路线的结果在报告中做交叉验证：一致时增强信心，不一致时标注分歧供投资者自行判断。情绪区间参考 CNN Fear & Greed Index 的划分方式（恐慌/谨慎/中性/乐观/贪婪），中性区间最窄（仅 11 分），体现市场大部分时间非恐即贪的设计理念。

第三步：事件识别 + 交易信号（event_detector.py）

采用了关键词优先 + LLM 兜底的混合模式：

  1. 关键词快速检测：预先设计了三级关键词字典——

    • 利好类：资产重组、回购增持、业绩预增、股权激励、大额订单、分红送转、提价调价、主力资金流入
    • 利空类：业绩预减、违规处罚、股东减持、商誉减值、退市风险、诉讼仲裁、主力资金流出、解禁限售
    • 政策类：降准降息（货币政策）、产业政策、监管新规

  2. LLM 精细识别（可选，--use_llm）：对关键词未命中的新闻，交给 LLM 做补充判断，捕捉关键词库覆盖不到的事件。

  3. 信号映射：通过预定义的事件-信号字典（SIGNAL_MAP），将识别出的事件映射为具体的交易信号（看多/看空/关注/回避/观望等），每条信号附带原因说明。

二、宏观维度：全球恐贪指数 + 风险传导

指标体系

通过 market_fear_index.py 获取多维度宏观指标，综合评估全球市场情绪：

指标 含义 数据来源 说明
VIX 标普500 的 30 日隐含波动率（恐慌指数） 新浪财经（akshare VX 期货） CBOE VIX 期货近似现货
OVX（代理） 原油波动率 WTI 原油期货 20 日年化实现波动率 akshare 无 OVX 直接接口，用 CL 期货计算代理值
US10Y 美国 10 年期国债收益率 新浪财经（akshare） 全球资产定价之锚
A股情绪（可选） 上证指数涨跌 + 北向资金 akshare 通过 --include_akshare 开启

工程决策：OVX 和 GVZ（黄金波动率）在 akshare 中没有直接 API，我选择用 WTI 原油期货（CL）和 COMEX 黄金期货（GC）的收盘价计算 20 日年化实现波动率作为代理值。虽然实现波动率和隐含波动率在定义上有差异，但胜在国内网络直连可用、无需 VPN，且趋势方向一致。

综合恐贪评分算法

基准 50 分（中性），各指标按区间加减 delta 后钳位到 [0, 100]：

指标 最大正向 delta 最大负向 delta 权重占比
VIX +30（<15，极度平静） -30（>35，极度恐慌） ~53%
US10Y +10（<3.8%，宽松预期） -10（>4.8%，高利率压制） ~18%
OVX +5（<25%，能源稳定） -10（>40%，地缘风险） ~18%

风险传导分析（OVX × VIX 交叉判断）

参考开源证券研报的风险传导逻辑，在代码中实现为：

  • OVX 飙升（>40）但 VIX 滞后（<25）：风险仍集中在能源端，尚未传导至全球信用风险，无需全面避险
  • OVX 与 VIX 同步共振向上（均高位）：地缘风险已触发流动性危机，需立即风控，增配黄金和现金类资产

三、前瞻性维度：Polymarket 预测市场

通过 polymarket_monitor.py 接入 Polymarket 预测市场数据。Polymarket 是全球最大的去中心化预测市场，基于 Polygon 区块链（以太坊 L2），用户用 USDC（稳定币）押注事件发生的概率，所有交易链上透明可查。

API 架构

  • Gamma API（元数据层）：市场描述、标签、结算日期，免费无需认证
  • CLOB API（执行层）：实时价格、订单簿、成交历史
  • 结算层：链上 UMA 预言机（争议期 2 小时）

核心功能

  1. 事件概率监控：通过关键词搜索（如 Iran、tariff、war、Fed）获取活跃预测市场，展示事件概率和交易量
  2. 聪明钱信号检测：计算所有市场的平均交易量，筛选出交易量超过平均值 3 倍且概率高度倾斜的市场，这些通常反映大额资金的押注方向（可能包含内幕信息或专业分析）
  3. 资产配置建议：基于预定义的事件-资产映射规则（战争→做多黄金/原油，停火→平仓避险头寸等），结合概率极端度和交易量生成信号强度评分，输出 Top N 配置建议

经典案例

2025年2月27日，Polymarket 上 150 多个账户押注”美军空袭伊朗”事件，金额高达 80 万美元，次日美军确实发动空袭，这些账户获利 120 万美元。这个案例说明预测市场上确实存在内幕信息的流通，追踪聪明钱的押注方向有实际投资价值。

四、用户使用方式

用户通过自然语言提问，Agent 自动编排脚本调用链：

  • “帮我分析贵州茅台最近的消息面” → 微观三步链路 → 舆情分析报告
  • “A股最近有没有重大事件值得关注” → 关键词抓取 + 事件检测 → 事件列表
  • “现在全球市场情绪如何？适合加仓吗？” → 宏观恐贪指数 + Polymarket → 综合研判

最终输出一份结构化的 Markdown 分析报告，包含情绪评分表格、交叉验证结果、风险传导分析、聪明钱信号和资产配置建议。

五、技术亮点总结（面试加分项）

亮点 说明
多源聚合新闻抓取 东方财富 + DashScope 双数据源，--sources 参数灵活切换
双引擎搜索互补 Tavily（国际）+ DashScope（国内），解决单一引擎对中文小盘股覆盖不足
交叉验证机制 LLM 综合研判 vs 强度加权统计，两条独立路线对比增强结果可信度
关键词+LLM 混合事件检测 关键词保证速度，LLM 补充覆盖率，平衡效率与准确性
波动率代理方案 用期货实现波动率替代 OVX/GVZ 直接接口，解决数据源不可用问题
Skills 渐进式加载 nanobot 框架按需加载技能，避免 token 浪费
