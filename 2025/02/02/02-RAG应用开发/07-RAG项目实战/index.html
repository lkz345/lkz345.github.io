二. streamlit的使用

1. 简介

Streamlit 是一个开源的 Python 框架，允许开发者快速构建和部署数据科学和机器学习应用。不同于传统的 Web 开发，Streamlit 只需几行代码就能创建交互式数据应用。

官方文档:　https://docs.streamlit.io/get-started/installation

核心特点：

  • 🚀 极简开发：纯 Python 脚本即可创建 Web 应用
  • ⚡ 实时更新：文件保存自动刷新应用
  • 🧩 内置组件：丰富的小部件、布局和图表类型
  • ☁️ 轻松部署：支持一键部署
